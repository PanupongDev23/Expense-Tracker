# Demo Script: Expense Tracker

## Goal

Show how an idea becomes a clear product plan before coding, then demonstrate the minimum app flow.

## Opening

"This project starts from a broad idea: a personal expense tracker. Instead of coding immediately, we use AI planning tools such as Grill Me and Plan Mode to narrow scope into a buildable MVP."

## Demo Flow

1. Show `PRD.md`
2. Show `requirements.md`
3. Show `design.md`
4. Show `tasks.md`
5. Open deployed app
6. Register or login
7. Add income: Salary 30000
8. Add expense: Food 250
9. Add expense: Transport 80
10. Open dashboard and show totals
11. Set monthly budget: 10000
12. Show budget status

## Key Talking Points

- The original idea was too broad for a class demo.
- The MVP focuses on one complete working flow.
- Vercel and Neon are suitable because they keep deployment and database setup simple.
- The spec files reduce ambiguity before implementation.

## Closing

"The important lesson is that AI is not only for generating code. It can help clarify scope, define acceptance criteria, design data models, and create an implementation checklist before we start coding."
